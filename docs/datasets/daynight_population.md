# daynight_population — 国勢調査 昼夜間人口（従業地・通学地集計）

国勢調査（e-Stat）の **常住地又は従業地・通学地別人口（夜間人口・昼間人口）** を、
1990〜2020 の全年について精製するデータセット群。単年の基底データは全国／都道府県／市区町村の
全階層を含むが、**時系列の正典（`daynight_population_timeseries`）は合併畳み込み済みの
市区町村アトムに統一**する（`--join aggregate_to_base`。[population.md](population.md) /
[population_by_age.md](population_by_age.md) と同規格。全国・都道府県は area_code 先頭2桁で束ねる派生ビュー）。
昼夜間人口・昼夜間人口比率（通勤通学による昼間の人口流出入）を提供する。

> **ステータス:** 実装済み（2026-08-10）。**area master（共有ディメンション）を無改修で再利用した
> 「3例目」**。cleaner=`clean_daynight_population`（全年1個）／datasets 7表＋`daynight_population_timeseries`。
> combine・area 集約（`aggregate_to_base` / `crosswalk`）・reconcile は分類軸コード列（`*_code`）の
> 自動判別で吸収され、[population.md](population.md) / [population_by_age.md](population_by_age.md) と
> 同じコードパスに乗る（共有インフラへの変更ゼロ・追加は cleaner ＋ datasets エントリのみ）。
> パイプライン全体設計は [apps/pipeline/README.md](../../apps/pipeline/README.md) を参照。

1980/1985 は該当表なし＝**1990-2020 の7年**。area 軸は JIS コード・全国(00000)行ありで
[population_by_age.md](population_by_age.md) と同型なので、地域マスタ（アトム抽出・rollup）が
そのまま効く。出典はいずれも「政府統計の総合窓口(e-Stat)」。

軸 `cat01`「常住地又は従業地・通学地による人口」は通勤流動の内訳を多数持つが、**内訳コード集合は
年で非同型**（2000=11・2020=14 コード）。全年で安定して存在し経年比較可能な2つの「総数」だけを採る:

| cat01 コード | 意味                                          | 採否                      |
| ------------ | --------------------------------------------- | ------------------------- |
| `100`        | 常住地による人口\_総数（夜間人口）            | ✅ `daynight_code=0`      |
| `180`        | 従業地・通学地による人口\_総数（昼間人口）    | ✅ `daynight_code=1`      |
| 110〜230     | 通勤流動の内訳（自宅/自市区町村/他市区町村…） | ❌ 年で非同型のため不採用 |

## 出力スキーマ

grain = **area × year × daynight**。`population` の8列と同型（sex を daynight に置換）。

| 列              | 型   | 説明                                               |
| --------------- | ---- | -------------------------------------------------- |
| `area_code`     | str  | 地域コード（JIS）                                  |
| `area_name`     | str  | 地域名                                             |
| `area_level`    | int  | 階層                                               |
| `daynight_code` | str  | 0=夜間人口（常住地）/ 1=昼間人口（従業地・通学地） |
| `daynight`      | str  | 名称                                               |
| `year`          | int  | 調査年                                             |
| `population`    | int  | 人口（欠損は null）                                |
| `is_current`    | bool | 現存自治体か（level 7=旧市区町村は false）         |

SQLite テーブル名は `daynight_population`。出力ファイルの役割は `population` と同一。

### なぜ `daynight_code=0` を夜間人口に割り当てるか（総数スライスの意味）

reconcile の人口保存は「総数スライス（全 `*_code`=="0"）」で検査する。sex/age は 0=総数・
内訳が 0 へ合算される**入れ子**だが、昼夜間は 0（夜間）と 1（昼間）が畳んで総数にならない
**並列な2母集団**である。そこで **夜間人口（＝常住地人口＝通常の居住人口）を 0** に割り当て、
総数スライスが population と同じ「居住人口の保存」を指すようにする。

- **クロスファクト検算:** 夜間人口の全国値は `population` ファクトと一致する
  （実測: 2020=126,146,099 / 2015=127,094,745、全7年 diff=0）。
- 昼間人口（code 1）は `aggregate_to_base` / `crosswalk` で daynight_code ごとに独立に
  合併集約され、全国では昼間=夜間（国外通勤なし）＝同値になる。
- スポット検算（2020 千代田区）: 夜間 66,680 / 昼間 903,780 ＝ 昼夜間人口比率 13.6 倍。

## 検証（実データ・全7年）

- **人口保存（`national_conservation`）:** 各年「アトム合計（夜間総数）== 全国total」＝全7年 diff=0。
- **孤児（`orphans`）:** 0 件（全消滅アトムが base_year へ到達）。
- **集約:** `aggregate_to_base` / `crosswalk` とも daynight 軸を保ったまま合併集約が成立。
- **単体テスト:** cleaner（`test_daynight.py`）＋ 並列2母集団の集約・総数スライス（`test_area.py`）。

> **設計上の含意（一般化の答え合わせ）:** 「総数スライス = 全 `*_code`=="0"」の前提は、
> _ある分類軸コードが全国値を保存する_ 限り成立する。sex/age（入れ子）でも daynight（並列）でも
> 「0 に保存する母集団を割り当てる」だけで共有インフラが無改修で乗ることを本ファクトが実証した。
