# occupation — 国勢調査 職業（大分類）×男女別就業者数

国勢調査（e-Stat）の **職業（大分類），男女別就業者数及び人口構成比［職業別］（15歳以上就業者）**
（時系列データ製品 全国 `0003410408` / 都道府県 `0003410411`）を、**全国 1995〜2020／都道府県
2005〜2020** の 1 枚テーブルに精製するデータセット。産業（[industry](industry.md)）と対になる
**就業構造の職業軸**を提供し、職業別就業者数・職業構成比（＝各職業÷総数）で「どんな仕事に就いて
いるか」と「職業構成の変化」を描ける。

> **ステータス:** 実装済み（2026-08-16）。**[industry](industry.md) と軸構造が完全同型**（tab=334就業者数/
> 構成比・cat01=大分類2015・cat02=男女・全国表 area 軸なし）で、occupation.py は industry.py を職業向けに
> 写したもの。**全国表が area 軸を持たない**ため全国合成の `clean_national`（00000/全国/level1 を合成）と
> 実 area の `clean_prefecture` の2 cleaner（`national` フラグ分岐）。派生の `occupation_timeseries` は
> 全国＋47県を area 軸で単純 union するだけ（合併 rollup なし・area master 不要）。
> 帳票の位置づけ（就業状態等基本集計＝人口等基本集計とは別の親）は
> [census_source_tables.md](census_source_tables.md) §3-6。

## データソース

| statsDataId | 帳票名                                                           | 粒度・期間                      |
| ----------- | ---------------------------------------------------------------- | ------------------------------- |
| 0003410408  | 職業(大分類)，男女別就業者数及び人口構成比［職業別］ － 全国     | 全国(level1) / 1995〜2020       |
| 0003410411  | 職業(大分類)，男女別就業者数及び人口構成比［職業別］ － 都道府県 | 47都道府県(level2) / 2005〜2020 |

- **別の親（就業状態等基本集計）**：industry と同じく人口等基本集計ではなく第2次＝就業状態等基本集計に属す
  （混同注意・§3-6）。職業分類は平成21年12月改訂後の「職業大分類2015」体系。
- **age5 と同型（全国表が area 軸なし）**：全国表 0003410408 は area 軸を持たない→00000/全国/level1 を合成し、
  都道府県表 0003410411 は area=47都道府県(level2) をそのまま採る。分類コード（100・110〜220）は両表一致。
- **年カバレッジは非対称**：全国は 1995〜2020 の 6 時点、都道府県は 2005〜2020 の 4 時点（全国のみ 1995/2000）。
  union はこの非対称を許容する（area×職業×year の disjoint）。
- 2015/2020 は「不詳補完値」版(time_code 末尾 `000010`)が併存するため通常版(`000000`)に統一する。
- 出典は「政府統計の総合窓口(e-Stat)」。

### 軸の採否

| 軸             | コード            | 採否                                                              |

| tab 334        | 就業者数          | ✅ `workers`                                                      |

## 出力スキーマ

grain = **area × sex × occupation × year**。[industry](industry.md) の10列を土台に、industry を
occupation に差し替えた同型。

| 列                | 型   | 説明                                                      |
| ----------------- | ---- | --------------------------------------------------------- |
| `area_code`       | str  | 地域コード（00000=全国 / 47都道府県）                     |
| `area_name`       | str  | 地域名                                                    |
| `area_level`      | int  | 階層（1=全国 / 2=都道府県）                               |
| `sex_code`        | str  | 0=総数 / 1=男 / 2=女                                      |
| `sex`             | str  | 名称                                                      |
| `occupation_code` | str  | 100総数 / 110〜220 職業大分類12区分（220=分類不能の職業） |
| `occupation`      | str  | 名称（Ａ管理的職業従事者 … Ｌ分類不能の職業）             |
| `year`            | int  | 調査年                                                    |
| `workers`         | int  | 15歳以上就業者数（欠損は null）                           |
| `is_current`      | bool | 現存自治体か（本表は level7 を持たず常に true）           |

### 不詳の扱い（導出注入は無い）

industry と同じく、**「分類不能の職業」(220) が実カテゴリとして原表に存在する**ため、
`総数(100) == Σ大分類(110〜220)` が原資料で恒等成立する（導出注入は不要）。

**保存則:**

- **職業内訳保存**（主）: 各 area×sex×year で `Σ大分類(110〜220・分類不能含む) == 総数(100)`
  - 都道府県（2005〜2020）: **全 area×sex×year で違反 0**。
  - ⚠ **全国 1995/2000 のみ既知差分**：総数と Σ大分類が **±1人** ずれる（原資料が当該2年のみ丸めた値を収録。
    2005 以降は完全一致）。override では解消しない原資料の丸めなので値はそのまま保持し記録に留める
    （industry の数千人差・labor_force 1955 男の 100 人差と同種）。
- **地域集約保存**: 各 sex×occupation×year（共通年 2005〜2020）で `47都道府県合計 == 全国` が **差分 0 で完全一致**。
- **男女保存**: 各 area×occupation×year で `男(1) + 女(2) == 総数(0)`

## 使い方

```bash
uv run poe run occupation_national       # 全国（0003410408, 1995〜2020）
uv run poe run occupation_prefecture     # 都道府県（0003410411, 2005〜2020）
uv run poe run occupation_timeseries     # 全国＋47県を union した配布正典
uv run poe clean occupation_national     # 先頭を確認（書き出しなし）
```

職業構成比は配布側で count から算出する（`各職業 workers / 総数(100) の workers`）。
