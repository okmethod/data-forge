# データソースカタログ

公的データ・オープンデータの利用規約・商用可否・再配布可否・API提供状況をまとめる。

**凡例：** ✅ 可 / ⚠️ 要確認 / ❌ 不可

**注意：商用可否と再配布可否は別物：**

- **商用可否** … 加工・分析して得た成果を商用目的で「利用」してよいか。
- **再配布可否** … データ自体（加工済み Parquet / CSV / SQLite 等）を第三者へ「配布」してよいか。加工データを頒布する場合はこちらが効く。
- CC BY 系（出典表記のみ）は再配布まで許容されるのが基本。一方、**コピーレフト（ODbL 等）は派生物にも同ライセンスの公開が伝播**するため、クローズドな加工データとして頒布できない点に注意。

## e-Stat（政府統計の総合窓口）

- **提供元：** 総務省統計局
- **ライセンス：** [統計データ利用規約](https://www.e-stat.go.jp/terms-of-use)（CC BY 4.0 相当）
- **商用可否：** ✅ 可（出典表記必要）
- **再配布可否：** ✅ 可（CC BY 4.0 相当。出典表記＋加工した旨の明示で、加工済みデータの配布まで可）
- **API：** ✅ あり（JSON / CSV / XML）
- **主な内容：** 国勢調査・住宅土地統計・経済センサス・農業センサス 等
- **出典表記例：** `出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）`
- **備考：** APIキーの取得が必要。レスポンスのJSON構造が複雑でメタデータのパースに工夫が必要。

## e-Stat 廃置分合等情報（合併イベントの出所）

- **提供元：** 総務省（e-Stat「政府統計の総合窓口」経由。総務省「全国地方公共団体コード」の改正履歴）
- **ライセンス：** [全国地方公共団体コード](https://www.soumu.go.jp/denshijiti/code.html)（政府標準利用規約＝CC BY 4.0 相当）／e-Stat [統計データ利用規約](https://www.e-stat.go.jp/terms-of-use)
- **商用可否：** ✅ 可（出典表記必要）
- **再配布可否：** ✅ 可（CC BY 4.0 相当。コード自体は事実データで著作物性が低い）
- **API：** ⚠️ 当面は e-Stat の検索フォーム経由で手動 CSV ダウンロード（自動フェッチは後追い）
- **主な内容：** 市区町村コードの改正履歴（廃置分合＝新設/合体・編入・境界変更・分割・改称 等の種別付き。1970〜、改正前後のコード/名称と施行年月日）
- **用途：** area 層の**合併イベント（events）**の一次情報（`data/area/events_parsed.csv`）。
  生CSV（`data/raw/history/`）を `area/history/ingest.py` で正規化し、`old_code/successor_code/year/kind` の
  events スキーマへ写像する。code 体系が人口データ（e-Stat）と一致するのが採用理由。
  埋まらない/種別が別扱いの箇所だけを人手 overrides（`data/area/events_overrides.csv`＝堀）で補う。
- **出典表記例：** `総務省「全国地方公共団体コード」（政府統計の総合窓口(e-Stat)）`
- **備考：** 生CSVの実列名は実物入手後に `ingest.py` の `_RAW_COLS` で確定する運用（現状は想定値=TODO）。
  合算に効くのは合併系の種別で、境界変更・分割・改称は人口保存を崩す/別扱いのため overrides 側で個別対応する。
