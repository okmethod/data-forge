# データソースカタログ

公的データ・オープンデータの利用規約・商用可否・再配布可否・API提供状況をまとめる。

**凡例：** ✅ 可 / ⚠️ 要確認 / ❌ 不可

**注意：商用可否と再配布可否は別物：**

- **商用可否** … 加工・分析して得た成果を商用目的で「利用」してよいか。
- **再配布可否** … データ自体（加工済み Parquet / CSV / SQLite 等）を第三者へ「配布・再販」してよいか。本プロジェクトの有料販売（BOOTH等）はこちらに該当し、こちらが効く。
- CC BY 系（出典表記のみ）は再配布・再販まで許容されるのが基本。一方、**コピーレフト（ODbL 等）は派生物にも同ライセンスの公開が伝播**するため、閉じた有料商品にできない点に注意。

## e-Stat（政府統計の総合窓口）

- **提供元：** 総務省統計局
- **ライセンス：** [統計データ利用規約](https://www.e-stat.go.jp/terms-of-use)（CC BY 4.0 相当）
- **商用可否：** ✅ 可（出典表記必要）
- **再配布可否：** ✅ 可（CC BY 4.0 相当。出典表記＋加工した旨の明示で、加工済みデータの配布・再販まで可）
- **API：** ✅ あり（JSON / CSV / XML）
- **主な内容：** 国勢調査・住宅土地統計・経済センサス・農業センサス 等
- **出典表記例：** `出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）`
- **備考：** APIキーの取得が必要。レスポンスのJSON構造が複雑でメタデータのパースに工夫が必要。
