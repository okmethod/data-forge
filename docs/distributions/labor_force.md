# labor_force — 国勢調査 労働力状態（3区分）×男女別人口

国勢調査（e-Stat）の **労働力状態（3区分），男女別人口及び労働力率（15歳以上）**（時系列データ製品全国 `0003412175` / 都道府県 `0003412176`）を、**全国・47都道府県 × 1950〜2020** に精製した**データセットの正典**。  
人口(person)・世帯(household)に続く**就業構造の基幹軸**を提供し、労働力率（＝労働力人口÷(労働力人口+非労働力人口)）や完全失業率（＝完全失業者÷労働力人口）を分析できる。
高齢化（[age5year](age5year.md)）と対にすることで「働き手の減少」を描ける。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。
> 全国（`labor_force_national_timeseries`）と都道府県（`labor_force_prefecture_timeseries`）は**地理粒度排他**で別配布に分ける（原則・検証は [forged-dataset-catalog.md](forged-dataset-catalog.md#全国と都道府県の分離地理粒度排他)。実現は別 ID の upstream 分離）。

- **別の親（就業状態等基本集計）**：labor_force は人口等基本集計ではなく第2次＝就業状態等基本集計に属す。population 族と同じ e-Stat 編纂の時系列データ製品だが親集計が異なる（混同注意・就業状態等基本集計節）。
- **area master 不要**の低コスト fact：area 軸は全国(level1)＋47都道府県(level2)固定で旧市区町村(level7)を持たず合併の影響を受けない。全国は 0003412175、都道府県は 0003412176 と ID が分かれる（households と違い age5year と同じ2 ID 構成）が、両表の軸は完全同型なので cleaner は共用できる。
- **実在 15 時点**（1950/1955/…/2020）を運ぶ。2015/2020 は「不詳補完値」版が併存するため通常版に統一する（方針は [data-quality-assurance.md](../data-quality-assurance.md) の「不詳の扱い」）。

## 出力スキーマ

grain = **area × sex × labor_status × year**。
[age5year](age5year.md) の10列を土台に、age_class を labor_status に差し替えた同型。

| 列                  | 型   | 説明                                                                                      |
| ------------------- | ---- | ----------------------------------------------------------------------------------------- |
| `area_code`         | str  | 地域コード（00000=全国 / 47都道府県）                                                     |
| `area_name`         | str  | 地域名                                                                                    |
| `area_level`        | int  | 階層（1=全国 / 2=都道府県）                                                               |
| `sex_code`          | str  | 0=総数 / 1=男 / 2=女                                                                      |
| `sex`               | str  | 名称                                                                                      |
| `labor_status_code` | str  | 100総数 / 110労働力人口 / 120就業者 / 130完全失業者 / 140非労働力人口 / 999労働力状態不詳 |
| `labor_status`      | str  | 名称                                                                                      |
| `year`              | int  | 調査年                                                                                    |
| `population`        | int  | 15歳以上人口（欠損は null）                                                               |
| `is_current`        | bool | 現存自治体か（本表は level7 を持たず常に true）                                           |

**保存則:**

- **3区分保存**（主・全年違反0）: `労働力人口(110) + 非労働力人口(140) + 不詳(999) == 総数(100)`
- **労働力人口内訳保存**（副）: `就業者(120) + 完全失業者(130) == 労働力人口(110)`
  - ⚠ **既知差分 1件**：1955 年・男で 就業者+完全失業者 が 労働力人口より **100人少ない**（e-Stat 原数値の差分。override では解消しない原資料の真実として受容）。3区分保存には影響しない。
- **男女保存**: 各 area×labor_status×year で `男(1) + 女(2) == 総数(0)`

**労働力率の再現**（値一致を実証）: 2020 全国総数 = `110 / (110+140) = 59,949,767 / 96,553,735 = 62.08954%`＝公表 tab=1240 と完全一致。

**派生指標:** 労働力率・完全失業率は配布側で count から算出する（労働力率＝`110/(110+140)`、完全失業率＝`130/110`）。

### 労働力状態不詳の導出注入（人口保存の閉じ方）

原表は総数(100)＝労働力人口(110)＋非労働力人口(140) では閉じず、差分＝**労働力状態不詳**が暗黙に存在する（近年は無視できず 2020 全国は約1,170万人）。
cat01 に不詳コードが無いため、各 area×sex×year で**不詳(999) = 総数(100) − 労働力人口(110) − 非労働力人口(140)** を導出注入する（就業者(120)/完全失業者(130)は 110 の再掲なので減算に含めない）。
閉じ方の共通規約は [data-quality-assurance.md](../data-quality-assurance.md) の「不詳の扱い」。
