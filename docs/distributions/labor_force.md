# labor_force — 国勢調査 労働力状態（3区分）×男女別人口

国勢調査（e-Stat）の **労働力状態（3区分），男女別人口及び労働力率（15歳以上）**（時系列データ製品
全国 `0003412175` / 都道府県 `0003412176`）を、**全国＋47都道府県 × 1950〜2020** の 1 枚テーブルに
精製するデータセット。人口(person)・世帯(household)に続く**就業構造の基幹軸**を提供し、労働力率
（＝労働力人口÷(労働力人口+非労働力人口)）や完全失業率（＝完全失業者÷労働力人口）を分析できる。
高齢化（[population_by_age5](population_by_age5.md)）と対にすることで「働き手の減少」を描ける。

> **ステータス:** 実装済み（2026-08-16）。**単一 ID で全年・47県固定＝合併なし＝area master 不要**
> （[population_by_age5.md](population_by_age5.md) と同性格）。全国表・都道府県表とも実 area 軸を持つため
> age5 のような全国合成すら不要で、**cleaner `clean_labor_force` 1 個を両表で共用**する。派生の
> `labor_force_timeseries` は全国＋47県を area 軸で単純 union するだけ（合併 rollup なし）。
> パイプライン全体設計は [docs/pipeline-architecture.md](../pipeline-architecture.md) を参照。
> 帳票の位置づけ（就業状態等基本集計＝人口等基本集計とは別の親）は
> [census_source_tables.md](census_source_tables.md) §3-6。

## データソース

| statsDataId | 帳票名                                                  | 粒度・期間                    |
| ----------- | ------------------------------------------------------- | ----------------------------- |
| 0003412175  | 労働力状態(3区分)，男女別人口及び労働力率 － 全国        | 全国(level1) / 1950〜2020     |
| 0003412176  | 労働力状態(3区分)，男女別人口及び労働力率 － 都道府県    | 47都道府県(level2) / 1950〜2020 |

- **別の親（就業状態等基本集計）**：labor_force は人口等基本集計ではなく第2次＝就業状態等基本集計に属す。
  population 族と同じ e-Stat 編纂の時系列データ製品だが親集計が異なる（混同注意・§3-6）。
- **area master 不要**の低コスト fact：area 軸は全国(level1)＋47都道府県(level2)固定で旧市区町村(level7)を
  持たず合併の影響を受けない。全国は 0003412175、都道府県は 0003412176 と ID が分かれる（households と違い
  age5 と同じ2 ID 構成）が、両表の軸は完全同型なので cleaner は共用できる。
- **実在 15 時点**（1950/1955/…/2020）を運ぶ。2015/2020 は「不詳補完値」版(time_code 末尾 `000010`)が
  併存するため通常版(`000000`)に統一する（age5・population_by_age と同方針・補完版の混入は二重計上）。
- 出典は「政府統計の総合窓口(e-Stat)」。

## 出力スキーマ

grain = **area × sex × labor_status × year**。[population_by_age5](population_by_age5.md) の10列を土台に、
age_class を labor_status に差し替えた同型。

| 列                  | 型   | 説明                                                             |
| ------------------- | ---- | ---------------------------------------------------------------- |
| `area_code`         | str  | 地域コード（00000=全国 / 47都道府県）                            |
| `area_name`         | str  | 地域名                                                           |
| `area_level`        | int  | 階層（1=全国 / 2=都道府県）                                      |
| `sex_code`          | str  | 0=総数 / 1=男 / 2=女                                             |
| `sex`               | str  | 名称                                                            |
| `labor_status_code` | str  | 100総数 / 110労働力人口 / 120就業者 / 130完全失業者 / 140非労働力人口 / 999労働力状態不詳 |
| `labor_status`      | str  | 名称                                                            |
| `year`              | int  | 調査年                                                          |
| `population`        | int  | 15歳以上人口（欠損は null）                                      |
| `is_current`        | bool | 現存自治体か（本表は level7 を持たず常に true）                  |

### 労働力状態不詳の導出注入（人口保存の閉じ方）

原表は総数(100)＝労働力人口(110)＋非労働力人口(140) では閉じず、差分＝**労働力状態不詳**が暗黙に存在する
（近年は無視できず 2020 全国は約1,170万人）。cat01 に不詳コードが無いため、各 area×sex×year で
**不詳(999) = 総数(100) − 労働力人口(110) − 非労働力人口(140)** を導出注入する（就業者(120)/完全失業者(130)は
110 の再掲なので減算に含めない）。age5 の年齢不詳と同じ閉じ方。

**保存則:**

- **3区分保存**（主・全年違反0）: `労働力人口(110) + 非労働力人口(140) + 不詳(999) == 総数(100)`
- **労働力人口内訳保存**（副）: `就業者(120) + 完全失業者(130) == 労働力人口(110)`
  - ⚠ **既知差分 1件**：1955 年・男で 就業者+完全失業者 が 労働力人口より **100人少ない**（e-Stat 原数値の差分。
    override では解消しない原資料の真実として受容）。3区分保存には影響しない。
- **男女保存**: 各 area×labor_status×year で `男(1) + 女(2) == 総数(0)`

**労働力率の再現**（値一致を実証）: 2020 全国総数 = `110 / (110+140) = 59,949,767 / 96,553,735 = 62.08954%`
＝公表 tab=1240 と完全一致。

## 使い方

```bash
uv run poe run labor_force_national       # 全国（0003412175）
uv run poe run labor_force_prefecture     # 都道府県（0003412176）
uv run poe run labor_force_timeseries     # 全国＋47県を union した配布正典
uv run poe clean labor_force_national     # 先頭を確認（書き出しなし）
```

労働力率・完全失業率は配布側で count から算出する（労働力率＝`110/(110+140)`、完全失業率＝`130/110`）。
