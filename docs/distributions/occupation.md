# occupation — 国勢調査 職業（大分類）×男女別就業者数

国勢調査（e-Stat）の **職業（大分類），男女別就業者数及び人口構成比［職業別］（15歳以上就業者）**を精製した**データセットの正典**。  
産業（[industry](industry.md)）と対になる**就業構造の職業軸**を提供し、職業別就業者数・職業構成比（＝各職業÷総数）で「どんな仕事に就いているか」と「職業構成の変化」を描ける。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。

---

## 分類体系の呼称（SSoT）

> **この節が呼称の唯一の定義元。** 職業大分類は分類改訂で 2 系統に分かれる。
> data-forge では両者を**大分類の区分数**で `major<N>` と命名し、**以降このドキュメント・収集データカタログ [estat-census-catalog.md](../sources/estat-census-catalog.md)・datasets.py・[data-quality-assurance.md](../data-quality-assurance.md)・コード（occupation.py / test_occupation.py）でこの呼称のみを使う**（「2015体系」「旧大分類」「12区分」「改訂前/後」等の別表現は本節以外で使わない）。

| 呼称（canonical） | table_name           | 正式分類（＝定義）                                 | 大分類 | ソース 全国 / 都道府県  | 期間 全国 / 都道府県    |
| ----------------- | -------------------- | -------------------------------------------------- | ------ | ----------------------- | ----------------------- |
| **major12**       | `occupation_major12` | 職業大分類（2015年国勢調査基準＝2009年12月改訂後） | 12区分 | 0003410408 / 0003410411 | 1995〜2020 / 2005〜2020 |
| **major10**       | `occupation_major10` | 職業大分類（2009年12月改訂**前**・旧大分類）       | 10区分 | 0003410409 / 0003410412 | 1950〜2005 / 1980〜2005 |

**なぜ別テーブルか:** 2009年（平成21年）12月改訂で大分類が **10→12** に再編された（旧「H運輸・通信／I生産工程・労務」が「生産工程／輸送・機械運転／建設・採掘／運搬・清掃・包装」等へ分割）。
**同符号でも中身が違う**（例：符号 A は major12=管理的／major10=専門的・技術的）ため 10↔12 は**コード写像できず**、union せず別テーブルに分ける。
区分数で名付けるのは「新旧」が相対的で year 列とも紛れる年号を避けるため。

> 産業（[industry](industry.md)）も分類改訂（2007年11月）を持つため、遡及時は同じ **major\<N\>** 規約を適用する。
> 通称「2015体系」は産業・職業で改訂年が違うのに同名になり紛らわしいので、data-forge では区分数の major\<N\> を正とする。

- **別の親（就業状態等基本集計）**：industry と同じく人口等基本集計ではなく第2次＝就業状態等基本集計に属す（混同注意・就業状態等基本集計節）。

- **major10 の（再掲）行**（210〜240＝1農林漁業関係／2生産・運輸関係／3販売・サービス関係／4事務・技術・管理関係）は class map に載せず**自動除外**する（Σ大分類での二重計上を防ぐ・産業の中間集計と同方針）。

## 出力スキーマ

grain = **area × sex × occupation × year**（major12/major10 とも同型10列）。
[industry](industry.md) の 10列を土台に industry を occupation に差し替えた同型。

| 列                | 型   | 説明                                                                   |
| ----------------- | ---- | ---------------------------------------------------------------------- |
| `area_code`       | str  | 地域コード（00000=全国 / 47都道府県）                                  |
| `area_name`       | str  | 地域名                                                                 |
| `area_level`      | int  | 階層（1=全国 / 2=都道府県）                                            |
| `sex_code`        | str  | 0=総数 / 1=男 / 2=女                                                   |
| `sex`             | str  | 名称                                                                   |
| `occupation_code` | str  | 100総数 / 大分類（major12=110〜220 ／ major10=110〜200）               |
| `occupation`      | str  | 名称（**セグメントで体系が違う**：同符号でも指す職業が異なる点に注意） |
| `year`            | int  | 調査年                                                                 |
| `workers`         | int  | 15歳以上就業者数（欠損は null）                                        |
| `is_current`      | bool | 現存自治体か（本表は level7 を持たず常に true）                        |

> ⚠ `occupation_code` は**セグメント間で意味が違う**（例：110 は major12=Ａ管理的／major10=Ａ専門的・技術的）。
> 2 テーブルを跨いで occupation_code で join・比較してはならない。

**保存則（major12）:**

- **職業内訳保存**: 各 area×sex×year で `Σ大分類(110〜220) == 総数(100)`
  - 都道府県（2005〜2020）: 全 area×sex×year で違反 0。
  - ⚠ 全国 1995/2000 のみ **±1人** の既知差分（原資料の丸め・2005 以降は完全一致）。
- **地域集約保存**: 各 sex×occupation×year（共通年 2005〜2020）で `47都道府県合計 == 全国` が **差分 0**。
- **男女保存**: 各 area×occupation×year で `男(1) + 女(2) == 総数(0)`。

**保存則（major10）— major12 より既知差分が大きい:**

- **職業内訳保存**: 各 area×sex×year で `Σ大分類(110〜200) == 総数(100)`
  - 都道府県（1980〜2005）: 全 area×sex×year で違反 0。
  - ⚠ 全国 **1965/1975 のみ ±5人**（原資料の丸め・major12 の ±1 と同種）。
- **地域集約保存**: `47都道府県合計 == 全国` は **総数(100) では常に一致**。だが**大分類の内訳で構造的差分**あり（等量・符号逆＝総数は保存されるが配分が全国表と県表で違う）。これは全国長期系列(0003410409)と県系列(0003410412)で **2000年以前の分類境界が異なる**ためで、override では解消しない原資料の差分：
  - 1980: 専門技術(110) **+5,821** ↔ 事務(130) **−5,821**
  - 1985: 販売(140) **+133,297** ↔ 生産工程・労務(190) **−133,297**
  - 1990: 販売(140) **+153,620** ↔ 生産工程・労務(190) **−153,620**
  - 1995: 販売(140) **+224,747** ↔ 生産工程・労務(190) **−224,747**
  - 2000・2005 は差分 0。→ **major10 では販売(140)/生産工程(190)の全国と 47県合計を 1985-1995 で厳密一致させられない**（総数は一致）。ダッシュボード等で「県積み上げ＝全国」を前提にしないこと。
- **男女保存**: 各 area×occupation×year で `男(1) + 女(2) == 総数(0)`（丸め由来の全国数件を除き成立）。

詳細は [data-quality-assurance.md](../data-quality-assurance.md)。

**派生指標:** 職業構成比は配布側で count から算出する（`各職業 workers / 総数(100) の workers`）。

### 不詳の扱い（導出注入は無い）

両版とも**「分類不能の職業」が実カテゴリとして原表に存在する**ため（major12=220／major10=200）、`総数(100) == Σ大分類` が原資料で恒等成立する（導出注入は不要・industry と同じ）。
