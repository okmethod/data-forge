## 精製データの2つの粒度層（マクロ／ミクロ）

各データセットは、粒度と時間カバレッジの異なる2層で構成される。

- **マクロ（都道府県粒度・長期）**: 全国・都道府県スケール。多くが一世紀（1920〜）の長期系列。合併の影響を受けない固定コードで単一帳票から安価に得られる。
- **ミクロ（市区町村粒度・近年）**: 市区町村スケール。各回調査の別々の帳票を合併畳込で接続した近年（多くは1980〜）の時系列。年ごとに形の違う帳票を縫い合わせる泥臭い経路を要する。

## 共有ディメンション（次元）

上記の fact 群とは別に、全ファクトが共有する**地域ディメンション（conformed dimension）** を内部に持つ。
これ自体は配布データセット（fact）ではなく、合併をまたぐ市区町村の連続時系列を成立させる**共有ハブ**（各 fact の合併集約・県/地方 rollup が参照する土台）。

| ディメンション                | 役割                                                                             |
| ----------------------------- | -------------------------------------------------------------------------------- |
| [area_master](area_master.md) | 地域マスタ（アトム軸スタースキーマ）＝合併集約 rollup の共有ハブ。全 fact が参照 |

## 各データセットドキュメントの構成

各 `<name>.md`（fact 系データセット）は共通の順序で書かれている。
どの doc も同じ場所に同じ種類の情報がある。

| セクション        | 内容                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| 冒頭              | 正典1文（このデータセットの定義・用途）＋本カタログへの位置づけリンク（blockquote）                              |
| `## データソース` | 取得元 statsDataId 表＋注記 → `### 軸の採否`（どの軸・コードを採る／捨てるかと理由）                             |
| `## 出力スキーマ` | grain（1行の粒度）→ 列定義表 → `**保存則:**`（満たすべき恒等式）→ `**派生指標:**`（配布側で算出する指標）        |
| （固有の注記）    | `### 不詳の扱い` ／ 年ごとのスキーマ差 ／ セグメント差 等、データセット固有の what（`###` で出力スキーマ配下）   |
| `## 検証`         | 保存則・スキーマを担保する単体テスト（関数名付き）と横断検算の所在。検証方針の正典は `data-quality-assurance.md` |

> **例外**: `population` は複数年×粒度の**データセット群**のため冒頭に `## データセット一覧` を持ち構成が一部異なる。`area_master` は fact でなく**次元**（上記「共有ディメンション（次元）」）のため、この標準構成に従わない専用 doc。
