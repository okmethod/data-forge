# daynight_population — 国勢調査 昼夜間人口（従業地・通学地集計）

国勢調査（e-Stat）の **常住地又は従業地・通学地別人口（夜間人口・昼間人口）** を、1990〜2020 の全年について精製した**データセット群の正典**。  
単年の基底データは全国／都道府県／市区町村の全階層を含むが、**時系列の正典（`daynight_population_timeseries`）は合併畳み込み済みの市区町村アトムに統一**する（`--join aggregate_to_base`。
[population.md](population.md) / [population_by_age.md](population_by_age.md) と同規格。全国・都道府県は area_code 先頭2桁で束ねる派生ビュー）。
昼夜間人口・昼夜間人口比率（通勤通学による昼間の人口流出入）を提供する。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。

**市区町村粒度の時系列ファミリー（本表＝ミクロ）は 1990 始まり**。area 軸は JIS コード・全国(00000)行ありで [population_by_age.md](population_by_age.md) と同型なので、地域マスタ（アトム抽出・rollup）がそのまま効く。出典はいずれも「政府統計の総合窓口(e-Stat)」。

### 1990 より前へ遡れない理由（e-Stat 実検索・2026-08-23）

「1985/1980 も縫い合わせで延ばせるか」を e-Stat 実検索で確認した結論は **連続延伸は不可**（population / population_by_age の 1920〜世紀延伸のようにはいかない）:

| 年       | 昼夜間人口（従業地・通学地別人口）の表                                                       | 粒度                             | 縫合可否                     |
| -------- | -------------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------- |
| 1990〜   | 本表ファミリー（`0003412192`〜 / `0004003060`）                                              | 市区町村まで                     | ✅ ミクロ                    |
| 1985     | `0000030636`（常住地3区分×男女×年齢10区分・従業地通学地別人口）                              | **都道府県まで（市区町村なし）** | △ 都道府県 マクロ なら単発可 |
| 1980以前 | **昼間人口の集計表そのものが e-Stat に無い**（`従業地` は就業者数のみ・`昼間`/`常住地` 0件） | —                                | ❌ 表が存在しない            |

- **市区町村（ミクロ）:** 1990 が最古。1985 は市区町村粒度の表が無いためミクロ（アトム＋合併畳込）には乗らない。
- **都道府県に落としても不可:** 既製の都道府県昼夜間時系列（`0003388620` 等）も 1995〜。旧単発表で遡れるのは **1985 のみ**で、**1980 が空白**（1975/1970 も無い）。よって系列は「1985 → 飛んで 1990〜」の歯抜けにしかならず、都道府県 マクロ を足しても純増は実質「1985 の1点」だけ。
- 加えて 1985 表は `常住地3区分×年齢10区分` 構造で、cat01=100/180 の「総数2つだけ採る」現行 cleaner とは別スキーマ（専用 cleaner が要る）。
- **判断: 見送り**（ミクロは 1990〜2020 のまま）。ダッシュボードの「昼夜間人口 1990〜2020」表記に 1985 だけ突き出す非対称を作る割に情報量が薄い。1985→1990 の昼夜間人口比率の動きを都道府県で見せたい等の具体的な物語が出た場合のみ、都道府県 マクロ（`0000030636` から従業地・通学地の総数を抽出）を検討する。

軸 `cat01`「常住地又は従業地・通学地による人口」は通勤流動の内訳を多数持つが、**内訳コード集合は年で非同型**（2000=11・2020=14 コード）。
全年で安定して存在し経年比較可能な2つの「総数」だけを採る:

| cat01 コード | 意味                                          | 採否                      |
| ------------ | --------------------------------------------- | ------------------------- |
| `100`        | 常住地による人口\_総数（夜間人口）            | ✅ `daynight_code=0`      |
| `180`        | 従業地・通学地による人口\_総数（昼間人口）    | ✅ `daynight_code=1`      |
| 110〜230     | 通勤流動の内訳（自宅/自市区町村/他市区町村…） | ❌ 年で非同型のため不採用 |

## 出力スキーマ

grain = **area × year × daynight**。
`population` の8列と同型（sex を daynight に置換）。

| 列              | 型   | 説明                                               |
| --------------- | ---- | -------------------------------------------------- |
| `area_code`     | str  | 地域コード（JIS）                                  |
| `area_name`     | str  | 地域名                                             |
| `area_level`    | int  | 階層                                               |
| `daynight_code` | str  | 0=夜間人口（常住地）/ 1=昼間人口（従業地・通学地） |
| `daynight`      | str  | 名称                                               |
| `year`          | int  | 調査年                                             |
| `population`    | int  | 人口（欠損は null）                                |
| `is_current`    | bool | 現存自治体か（level 7=旧市区町村は false）         |

SQLite テーブル名は `daynight_population`。出力ファイルの役割は `population` と同一。

**派生指標:** 昼夜間人口比率（＝昼間人口 ÷ 夜間人口、通勤通学による昼間の人口流出入）は配布側で算出する。

### なぜ `daynight_code=0` を夜間人口に割り当てるか（総数スライスの意味）

reconcile の人口保存は「総数スライス（全 `*_code`=="0"）」で検査する。sex/age は 0=総数・内訳が 0 へ合算される**入れ子**だが、昼夜間は 0（夜間）と 1（昼間）が畳んで総数にならない**並列な2母集団**である。
そこで **夜間人口（＝常住地人口＝通常の居住人口）を 0** に割り当て、総数スライスが population と同じ「居住人口の保存」を指すようにする。

- **クロスファクト検算:** 夜間人口の全国値は `population` ファクトと一致する（実測: 2020=126,146,099 / 2015=127,094,745、全7年 diff=0）。
- 昼間人口（code 1）は `aggregate_to_base` / `crosswalk` で daynight_code ごとに独立に合併集約され、全国では昼間=夜間（国外通勤なし）＝同値になる。
- スポット検算（2020 千代田区）: 夜間 66,680 / 昼間 903,780 ＝ 昼夜間人口比率 13.6 倍。
