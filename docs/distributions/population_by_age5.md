# population_by_age5 — 国勢調査 年齢5歳階級×男女別人口

国勢調査（e-Stat）の **年齢5歳階級（0〜4／5〜9／…／85歳以上）× 男女** 別人口を精製した**データセット群の正典**。  
`population_by_age`（年齢3区分）より細かい年齢構造の時系列を提供する。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。

**1 つの table_name `population_by_age5` に 2 系列が同居する**（粒度は key suffix で表し family 名には持たせない＝命名規約 `apps/pipeline/src/data_forge/datasets.py` docstring）:

| 系列                         | 粒度・カバレッジ                                         | 帳票の性質       | 配布 key                                   | cleaner             |
| ---------------------------- | -------------------------------------------------------- | ---------------- | ------------------------------------------ | ------------------- |
| **市区町村（ミクロ）**       | 市区町村（level4/6/7）・1980-2020（5年間隔）・**国籍別** | 回次別帳票を縫合 | `population_by_age5_timeseries`            | `age5_municipality` |
| **全国・都道府県（マクロ）** | 全国＋47都道府県・1920〜2020（一世紀・総人口）           | 回次跨帳票を射影 | `population_by_age5_prefecture_timeseries` | `age5`              |

> 両系列は別 statsDataId・別 stem（別配布ファイル）だが同じ table_name `population_by_age5` を共有する（N:1 ハブ）。
> 2010-2020 では県値が重なるため物理2重保存せず、市区町村→県 rollup==県マクロ を**検算オラクル**（test）で照合する。

---

## なぜ2系列に分かれるか（ソースの非対称）

同じ fact（5歳階級×男女別人口）でも、粒度によって e-Stat の供給形態が全く違うため、取得経路＝系列が2本に分かれる（table_name は共有・別 stem）。

- **全国・都道府県（マクロ）は安い**: 5歳階級が **1920〜2020 を単一 ID で提供**（下表）。合併の影響を受けない 47 コード固定＝**area master も合併集約も不要**の低コスト fact（回次跨帳票の射影）。
- **市区町村（ミクロ）は高い**: 市区町村×全年の綺麗な 5歳階級時系列は **e-Stat に存在しない**（時系列データ製品で市区町村まで下りる年齢表は[年齢3区分だけ](population_by_age.md)）。各回基本集計には市区町村5歳階級が 1980 から在るが、年ごとに別 statsDataId・別軸交差（総数と日本人が別表の年もある）と極めて不揃い（収集データカタログ [estat-census-catalog.md](../sources/estat-census-catalog.md) §3-3）。**各回（回次別帳票）を年ごとに取得して `aggregate_to_base` で合併畳込**する経路が必要。

以下の「データソース」「出力スキーマ」「合成」節は主に **マクロ（全国・都道府県）系列**を説明する。
ミクロ（市区町村）系列の固有事情（100歳以上・合併畳込・年別スキーマ差）は[市区町村ミクロ系列](#市区町村ミクロ系列)節にまとめる。

## データソース

| 粒度     | statsDataId | 帳票名                                                              | area 軸                          |
| -------- | ----------- | ------------------------------------------------------------------- | -------------------------------- |
| 全国     | 0003410380  | 年齢（5歳階級），男女別人口及び人口性比 － 全国（大正9年〜令和2年） | **なし**（＝全国のみ）           |
| 都道府県 | 0003410381  | 同上 － 都道府県（大正9年〜令和2年）                                | 47都道府県（level2・全国行なし） |

2 表は軸構造が**同型**（`getStatsData` で確認済み）:

| 軸      | 名称                    | コード                                                             |
| ------- | ----------------------- | ------------------------------------------------------------------ |
| `tab`   | 表章項目                | 020=人口 / 024=割合 / 1120=人口性比（**人口=020 のみ採用**）       |
| `cat01` | 男女\_時系列            | 100=総数 / 110=男 / 120=女                                         |
| `cat02` | 年齢（5歳階級）\_時系列 | 100=総数 / 110=0〜4歳 … 310=85歳以上（＋全国のみ細分・再掲、下記） |
| `time`  | 時間軸（調査年）        | 1920〜2020（5年間隔。2015/2020 は「不詳補完値」版が併存、下記）    |

差は次の 3 点だけで、`age5.clean_age5(tidy, *, national)` の `national` フラグ1個で吸収する:

1. **全国表(380)は area 軸を持たない** → `00000`／`全国`／`area_level=1` を合成する。
2. **都道府県表(381)のみ area=47都道府県**（level2）を持つ（全国行なし）。
3. **5歳階級コード集合の非対称**: 全国表は 85 歳以上を更に細分（85〜89…110歳以上＝320〜370）するが、都道府県表は **85歳以上(310)止まり**。両者で安定比較できる **85歳以上を終端**とし、全国のみの細分(320-370)と（再掲）15歳未満/15〜64歳/65歳以上(380-400＝5歳階級から導出可能)は捨てる。

> **不詳補完値版の扱い:** 2015/2020 は `time_code` 末尾 `000010`（例 `2020000010`）の「不詳補完値」版が併存する。
> 混ぜると方法論の継ぎ目＋二重計上になるため、`population_by_age` と同方針で**通常版(末尾 `000000`)に統一**する（補完版は将来の別バリアントとして任意）。

## 出力スキーマ

下表はマクロ（全国・都道府県）系列＝grain **area × year × sex × age_class**・`population_by_age` と同型の 10 列。
**ミクロ（市区町村）系列はこれに nationality 軸を足した 12 列**（`nationality_code`/`nationality` を `sex` の後に挿入・grain は area × year × sex × **nationality** × age_class）。
SQLite テーブル名は 2系列共有の `population_by_age5` だが別 stem＝別ファイルなので列差は物理的に同居しない（マクロは総人口専用で nationality 軸を持たない）。
ミクロは `area_level` に 4/6/7、`age_class_code` に 100歳以上（280〜310）、`year` は 1980-2020（5年間隔）、`is_current` にfalse（level7）が入る（差分は[マクロ（全国/県版）との違い](#マクロ全国県版との違い)）。

| 列               | 型   | 説明                                                                             |
| ---------------- | ---- | -------------------------------------------------------------------------------- |
| `area_code`      | str  | 地域コード（JIS。00000=全国 / 01000〜47000=都道府県）                            |
| `area_name`      | str  | 地域名                                                                           |
| `area_level`     | int  | 階層（1=全国 / 2=都道府県）                                                      |
| `sex_code`       | str  | 男女コード（0=総数 / 1=男 / 2=女）                                               |
| `sex`            | str  | 男女名称                                                                         |
| `age_class_code` | str  | 年齢5歳階級コード（e-Stat cat02 のまま。100=総数 … 310=85歳以上 / 999=年齢不詳） |
| `age_class`      | str  | 年齢5歳階級名称（総数 / 0〜4歳 … 85歳以上 / 年齢不詳）                           |
| `year`           | int  | 調査年（1920〜2020 の 5 年間隔）                                                 |
| `population`     | int  | 人口（欠損は null）                                                              |
| `is_current`     | bool | 現存自治体か（マクロは全国/都道府県のみ＝常に true。ミクロは level7 が false）   |

> **age_class_code は e-Stat の cat02 コードをそのまま採る**（3桁ゼロ埋め＝辞書順が年齢昇順で、出所が追える。18 区分を独自連番へ振り直す remap 表を持たない）。総数=100 が先頭、年齢不詳=999 が末尾。

### 年齢不詳（age_class_code=999）は導出行

**cat02 に「年齢不詳」の独立コードは無い**が、近年は不詳が無視できない（実測・全国 総数−5歳階級合計 ＝ 2020 で **8,952,924 人**）。
そのため **不詳 = 総数(100) − Σ(5歳階級)** を計算し `age_class_code=999` の行として注入する。
これにより **Σ(5歳階級) + 不詳 == 総数** が全地域・全年で恒等成立する（`population_by_age`と同じ人口保存の閉じ方）。

## 合成（timeseries）

各基底 upstream が既に全年（1920〜2020）を持つため、結合軸は **year ではなく area**（disjoint な `00000`＋47都道府県）。`population_by_age5_prefecture_timeseries` は両者の**単純 union**（`default_join="union"`）で、市区町村を持たない＝合併 rollup 不要＝**area master を通さない**。

```bash
uv run data-forge run population_by_age5_national               # 全国のみ（1920〜2020）
uv run data-forge run population_by_age5_prefecture             # 47都道府県
uv run data-forge run population_by_age5_prefecture_timeseries  # 全国＋都道府県（マクロ 配布正典）
```

## 市区町村ミクロ系列

上記マクロ系列（全国・都道府県・回次跨帳票・1920-2020）と対をなす**市区町村粒度**の5歳階級。
マクロ側には市区町村×全年の5歳階級が無いため、**各回の基本集計（回次別帳票）**を年ごとに取得して `aggregate_to_base` で合併畳込した市区町村長期時系列にする（population／population_by_age と同じ経路）。

**国籍(nationality)軸あり**（総数=0/日本人=1）。取れる基底が年で非対称＝**総数は 1980-2020 全年・日本人は 1990-2020**。
cleaner=`age5_municipality.clean_<year>`（年別）／datasets=`population_by_age5_{年}`（＋総数用 `population_by_age5_{1990,1995}_total`）＋`population_by_age5_timeseries`（table_name はマクロと共有・別 stem）。

> ソースの全 statsDataId・年別の軸割当/コード体系・国籍別の可否マトリクス・選定根拠（2000 の各歳表採用・2015 のgetMetaInfo 食い違い・`muni_levels={4,6}` 上書き必須 等）は収集データカタログが正典: [estat-census-catalog.md §3-3](../sources/estat-census-catalog.md)。本節は出力側（配布シェイプの差・保存則検証）に絞る。

### マクロ（全国/県版）との違い

同じ table_name `population_by_age5` を共有しつつ、粒度・年齢終端・不詳の扱いが非対称（別 stem＝別配布ファイルなので schema 差は同居しない）:

| 観点           | マクロ（全国/県版）                        | ミクロ（市区町村版）                                                 |
| -------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| 帳票の性質     | 回次跨帳票（単一ID・0003410380/381）       | 回次別帳票（各回別 statsDataId・年別 cleaner）                       |
| 配布 key       | `population_by_age5_prefecture_timeseries` | `population_by_age5_timeseries`                                      |
| nationality 軸 | なし（総人口専用）                         | **あり**（総数=0/日本人=1・総数は1980-2020全年・日本人は1990-2020）  |
| 年齢終端       | 85歳以上（310）                            | **100歳以上まで保持**（280〜310＝85-89…100歳以上）                   |
| age_class_code | 飛び番（140/270 欠番）                     | **5歳刻みの独自連番**（110=0〜4 … 270=80〜84 / 280〜310）            |
| 年齢不詳       | 導出注入（総数−Σ）                         | **実コードをそのまま採用**（1990/1995 は原表に不詳無し・注入しない） |
| area・合併     | 47県固定＝合併なし＝area master 非経由     | 市区町村（level4/6 アトム）＝**合併畳込あり**（level7 は 2020 のみ） |
| 年カバレッジ   | 1920-2020                                  | **1980-2020（5年間隔）**                                             |

粒度は key suffix で表し family 名（table_name）には持たせない、が命名規約（`datasets.py` docstring）。
ダッシュボードは 100歳以上まで持つミクロ系列で高齢化物語を精密化できる（総数スライス=nationality=0 でフィルタ・二重計上回避）。
