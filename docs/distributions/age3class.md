# age3class — 国勢調査 年齢3区分×男女別人口

国勢調査（e-Stat）の **年齢3区分（年少0-14／生産15-64／老年65+）× 男女** 別人口を、全国／都道府県／市区町村の粒度で 1980〜2020 の全年について精製した**データセット群の正典**。
高齢化の 45 年連続時系列を提供する。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。

---

## なぜ別データセットにするのか

`population`（男女別総人口）と `age3class` は **grain が違う別ファクト**であり、1 つの表に詰めず、共有ディメンション（area master）を囲む**星座型（fact constellation）**として横に並べる。
設計原理は [pipeline-architecture.md](../pipeline-architecture.md#星座型ハブ地域マスタ) が正典。

> **なぜ 1 ファミリーで済むか:** 現行 `population` は年ごとに設計の異なる複数の統計表を各年 cleaner でハーモナイズするが、**「年齢（3区分），男女別人口及び年齢別割合」表は単一ファミリーで 1980〜2020 全年を同一軸でカバー**する（下表）。
> この表は `population` が 1980-1995 で使う表（0003412413〜416）の ID 連番の続きで、`cat01=100`（年齢総数）で絞れば総人口をビット一致で再現できる。→ `age3class` は **cleaner 全年 1 個**で済む。

### 軸の採否

| 軸      | 内容                             | 採否                                                           |
| ------- | -------------------------------- | -------------------------------------------------------------- |
| `tab`   | 020=人口 / 105=割合              | ✅ 020 のみ（割合は人口から導出可能ゆえ捨てる）                |
| `cat01` | 年齢3区分（総数/年少/生産/老年） | ✅ 全コード保持（`100`=総数も捨てない）＋年齢不詳(9)を導出注入 |
| `cat02` | 男女（総数/男/女）               | ✅ 全コード保持                                                |
| `area`  | 都道府県／市区町村               | ✅ そのまま（**全国行なし**→都道府県合計から復元）             |

コード↔名称の写像・整形手順は cleaner の `AGE_TS` / `SEX_2005` と `clean_population_by_age` docstring が正典（[population.py](../../apps/pipeline/src/data_forge/sources/estat/population.py)）。

> **補完値版:** 2015/2020 に「【不詳補完値】」版（0003448300 / 0003448301）が併存する（2000-2010 には無い）。通常版に統一し、年齢不詳は下記の導出第4区分で明示保持する（方針は [data-quality-assurance.md](../data-quality-assurance.md) の「不詳の扱い」）。

## 都道府県 世紀マクロ（回次跨帳票・1920〜2020）

`age3class_prefecture` / `age3class_prefecture_timeseries`（cleaner=`clean_by_age_prefecture`）は、上記の市区町村ミクロ（各回別ID・1980〜）とは**別ソースの都道府県マクロ**で、5歳階級の `age5year_prefecture` と同じ役回り（回次跨帳票 raw を1920まで遡る世紀マクロ）。

- **ソース＝0003410383**「年齢（3区分）別人口及び年齢別割合 － 全国，都道府県（大正9年～令和2年）」。軸＝`tab`(1060=実数/105=割合)・`cat01`(年齢3区分 100総数/**105**=0-14/120=15-64/130=65+)・`area`(全国+47県)・`time`(1920〜2020)。**男女軸を持たない（総数のみ）**＝高齢化率の物語は総数で充足。2015/2020 は補完値版を通常版へ統一（→「不詳の扱い」）。
- **出力**＝ミクロと同じ10列。`sex` は総数固定。`age_class_code` はミクロ（`AGE_TS`）と同一ターゲット(`0/1/2/3/9`) へ揃える（0-14 はミクロ=110・本表=105 とコードは違うが写像先は共通）。
- **全国(00000)は落とし47都道府県のみ**（全国=Σ県で復元）。
- **クロスファクト**：1980-2020 の重複年は市区町村ミクロの県 rollup と一致（唯一の差＝東京都1980の+37人＝特別区部の区未定分＝回次跨帳票側が正しい県総数）。高齢化率 1920=5.3% / 1980=9.1% / 2020=28.7%。

> **fact 独立取得**：このマクロは 5歳階級を集約して作らず、3区分の自前の回次跨帳票(0003410383)から独立に取得する。cleaned 出力を別 fact の材料にしないことで、クロスファクト検算（5歳畳込==3区分 等）を「定義的に真」でなく実効の検算オラクルに保つ。

## 出力スキーマ

grain = **area × year × sex × age_class**。
`population` の 8 列に age_class の 2 列を足した 10 列。

| 列               | 型   | 説明                                                                                   |
| ---------------- | ---- | -------------------------------------------------------------------------------------- |
| `area_code`      | str  | 地域コード（JIS）                                                                      |
| `area_name`      | str  | 地域名                                                                                 |
| `area_level`     | int  | 階層（1=全国 / 2=都道府県 / 4=市 / 5=政令市の区 / 6=市区町村 / 7=旧市区町村）          |
| `sex_code`       | str  | 男女コード（0=総数 / 1=男 / 2=女）                                                     |
| `sex`            | str  | 男女名称                                                                               |
| `age_class_code` | str  | 年齢区分コード（0=総数 / 1=年少 / 2=生産年齢 / 3=老年 / 9=年齢不詳）                   |
| `age_class`      | str  | 年齢区分名称（総数 / 年少人口(0-14) / 生産年齢人口(15-64) / 老年人口(65+) / 年齢不詳） |
| `year`           | int  | 調査年                                                                                 |
| `population`     | int  | 人口（欠損は null）                                                                    |
| `is_current`     | bool | 現存自治体か（level 7=旧市区町村は false）                                             |

出力ファイル（`.parquet` / `.csv` / `.sqlite` / `.meta.json`）と役割は `population` と同一（[population.md](population.md#出力ファイルdataprocessedstem) 参照）。
SQLite テーブル名は `age3class`。

### 年齢不詳（age_class_code=9）は導出行

**時系列ファミリーの `cat01` は 総数/年少/生産/老年の 4 コードのみで、「年齢不詳」は独立コードとして存在しない。**
近年は不詳が無視できない（実測・東京都の 総数−3区分合計 ＝ 2000:46,848 → 2020:428,739 と経年増加）。
そのため **不詳 = 総数(100) − (年少 + 生産 + 老年)** を計算し、`age_class_code=9` の行として注入する。
これにより **年少 + 生産 + 老年 + 不詳 == 総数** が全年・全地域で恒等的に成立（人口保存が閉じる）。
導出注入は fact 共通の規約＝[data-quality-assurance.md](../data-quality-assurance.md) の「不詳の扱い」。

## 合併集約（地域マスタ）

ミクロ（市区町村・年またぎ）は市町村合併で地域集合が変わるため、後継自治体へ畳む共有ハブ **area master** に乗る（`population` と同じ経路）。area master は age 非依存で分類軸コード列（`*_code`）を自動追従するので、age3class は**キーを手足しせず**そのまま合併集約・保存検査に乗る。仕組みは共有ディメンションの [area_master.md](area_master.md) が正典。

> **次に何を星座に足せるか**（市区町村×経年で安く作れる話題の判定）は収集側の [estat-census-catalog.md](../sources/estat-census-catalog.md#兄弟ファクトの実現可能性時系列データ製品の市区町村カバレッジ) を参照（本 fact の what でなくソース選定のロードマップのため）。
