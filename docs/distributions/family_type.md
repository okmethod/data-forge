# family_type — 国勢調査 世帯の家族類型（16区分）別 世帯数・世帯人員

国勢調査（e-Stat）の **世帯の家族類型（16区分）別一般世帯数及び世帯人員 － 全国，都道府県**（時系列データ製品 `0003414255`、新分類区分）を、**全国＋47都道府県 × 1995〜2020** の 1 枚テーブルに精製した**データセットの正典**。  
単独世帯（単身世帯）・核家族世帯・親族のみ／非親族など**世帯の家族構成**を時系列で分析でき、単独世帯割合（＝単独世帯÷総数）による単身化の把握が主用途。

> 共通の位置づけ・関連ドキュメントは [forged-dataset-catalog.md](forged-dataset-catalog.md)。

## 出力スキーマ

grain = **area × family_type × year**（21コード × 48地域 × 6年 = 6,048 行）。
households の8列に `family_type_level` を足した9列。

| 列                  | 型   | 説明                                            |
| ------------------- | ---- | ----------------------------------------------- |
| `area_code`         | str  | 地域コード（00000=全国 / 47都道府県）           |
| `area_name`         | str  | 地域名                                          |
| `area_level`        | int  | 階層（1=全国 / 2=都道府県）                     |
| `family_type_code`  | str  | 100=総数 …（ツリー参照）… 290=単独 / 999=不詳   |
| `family_type`       | str  | 名称                                            |
| `family_type_level` | int  | ツリー階層（1〜4。不詳は 2）                    |
| `year`              | int  | 調査年                                          |
| `households`        | int  | 一般世帯数（欠損は null）                       |
| `household_members` | int  | 一般世帯人員（欠損は null）                     |
| `is_current`        | bool | 現存自治体か（本表は level7 を持たず常に true） |

**保存則:** 各 area×year で `総数(100) == 110 + 280 + 290 + 999` かつサブツリー
`110 == 120 + 170` / `120 == 130+140+150+160` / `170 == 180+…+270`（世帯数・世帯人員とも）。

**派生指標:** 単独世帯割合は配布側で `単独世帯(290) / 総数(100)` として算出する。

### 家族類型ツリー（cat01）と家族類型不詳(999)の導出注入

`family_type_code` は 4 階層のツリー。`family_type_level`（1〜4）で粒度を選べる。

```
100 総数 (level1)
├ 110 親族のみの世帯 (2)
│  ├ 120 核家族世帯 (3)
│  │  ├ 130 夫婦のみの世帯 (4)
│  │  ├ 140 夫婦と子供から成る世帯 (4)
│  │  ├ 150 男親と子供から成る世帯 (4)
│  │  └ 160 女親と子供から成る世帯 (4)
│  └ 170 核家族以外の世帯 (3)
│     └ 180〜270 (4)  ← 10区分（夫婦と両親／兄弟姉妹のみ 等）
├ 280 非親族を含む世帯 (2)
├ 290 単独世帯 (2)
└ 999 家族類型不詳 (2)  ← 導出注入
```

- 「**16区分**」＝葉16個（130-160・180-270・280・290）。100/110/120/170 は小計。
- **家族類型不詳(999) を導出注入**（labor_force の労働力状態不詳・age5 の年齢不詳と同型）：原資料の 総数(100) は level-2 の 110＋280＋290 を上回り、その残差＝家族類型不詳の世帯（2010〜2020 に発生・下表）。cat01 に独立コードが無いため **総数 − 親族のみ − 非親族 − 単独** として 999 を注入し、「110 + 280 + 290 + 999 == 100」を全地域・全年で閉じる（120/170 は 110 の内訳＝再掲ゆえ減算に含めない）。
